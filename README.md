Task 4 · Research Report: Common Network Security Threats
Objective

Research and document four common network security threats — DoS/DDoS, Man-in-the-Middle (MITM), IP Spoofing, and DNS Poisoning/Spoofing — covering how each attack works, a real-world example, its impact, and specific mitigation strategies.

Deliverable

The full report is available in two formats:

network_security_threats_report.md — Markdown version
network_security_threats_report.docx — Word version
Report Structure
Introduction — why network security threats matter in today's threat landscape
DoS/DDoS Attacks — how it works, real-world example (Mirai/Dyn, 2016), impact, 3 mitigations
Man-in-the-Middle Attacks — how it works, real-world example (Lenovo Superfish, 2015), impact, 3 mitigations
IP Spoofing — how it works, real-world example (GitHub memcached DDoS, 2018), impact, 3 mitigations
DNS Poisoning/Spoofing (bonus) — how it works, real-world example (DNSpionage/Sea Turtle, 2018–19), impact, 3 mitigations
Comparison table — attack vector, who is at risk, difficulty to execute, ease of mitigation, across all four threats
Conclusion — 3 key takeaways for a network administrator
References — NIST, CISA, MITRE ATT&CK, GitHub's official incident report, and industry security coverage
Methodology

Each threat and real-world example was researched using current, credible sources (NIST, CISA, MITRE ATT&CK, official incident post-mortems, and reputable security publications) rather than written from memory, to ensure technical accuracy and up-to-date incident details.
